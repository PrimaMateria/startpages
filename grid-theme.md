Ok I want to create a new experimental theme.
The look and feel should follow classic, even the color schemes can apply here.

The change is in the layout. Divide the screen to 3 columns - 25% 50% 25%. The
main column will contain grid - no mosaic. In this grid we render current page
columns. 

In the side columns will be supportive pages rendered with small font and in one
column. Now choose the pages simply with previous and next. You can cycle the
pages so the last page will show next page the first one.
